# Metadata schemas for OMERO "Screen" objects

The JSON schema file [screenschema.json](screenschema.json) defines all fields used for OMERO annotations. It includes a file upload field for biological metadata used to annotate individual wells. The Jupyter workflow expects this metadata to be provided as an Excel file, for which a template is supplied in [biologicalmetadata.xlsx](biologicalmetadata.xlsx).

Plasma metadata are collected using the plasma metadata schema [Plasma-MDS](https://github.com/plasma-mds/plasma-metadata-schema).
