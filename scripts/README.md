# Python scripts for the OMERO workflow

This directory contains the Python scripts needed to operate the Jupyter notebook workflow. <br>
[omerohandler.py](omerohandler.py) contains Python function definitions for OMERO related functions, which are utilized in the Jupyter notebook. <br>
[elabftwapihandler.py](elabftwapihandler.py) contains Python function definitions for eLabFTW related API functions, which are utilized in the Jupyter notebook.
